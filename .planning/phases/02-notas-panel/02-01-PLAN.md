## Planning Decisions (Claude's discretion, recorded)

- **Script layout:** `src/panel/panel.js` (DOM glue, no exports used by tests) and `src/panel/format.js` (pure helpers,
  no DOM, no top-level side effects besides building `Intl` formatters), plus `src/panel/format.d.ts` so `tsc` accepts
  typed imports. Real files read once at startup, not a string constant: no escaping of backticks, editor support, and
  the Dockerfile already copies `src/`. Editing them under `pnpm dev` needs a restart (node --watch does not watch files
  read with readFileSync); accepted.
- **Routes:** one `app.get('/admin/<name>')` per entry of `PANEL_SCRIPTS`, registered after the `/admin/*` guard. An
  explicit allow-list, no static-file middleware, so nothing else under `src/` can be fetched.
- **Columns:** the date column is titled Competência (D-05). A PDF column header exists from this plan; its cells stay
  empty until plan 02-03 fills them, and empty cells are hidden in card mode.
- **Mobile cards (D-10):** the same `<table>` restyled under `@media (max-width: 767px)` (Pico's own 768 px breakpoint),
  with explicit `role` attributes so the table semantics survive `display: block` (RESEARCH Pattern 7).
- **Emphasis (D-09):** weight and a left accent are the non-color cues; color comes from Pico variables.
- **Verification harness:** `scripts/panel-smoke.mjs` drives headless Chrome over CDP with no new dependency (Node's
  global WebSocket). It blocks cdn.jsdelivr.net so runs are offline and deterministic: checks rely on `/panel.css` and
  the DOM, never on Pico's colors. Pico's look is left to the end-of-phase human check. It is not part of `pnpm test`
  or CI (Chrome is a local verification aid, RESEARCH Environment Availability).

## Flagged Assumptions (research assumptions carried, not silently dropped)

- **A4:** explicit `role` attributes keep table semantics under `display: block`; checked only through the DOM, not a

- **A7:** Firefox and Safari were not run; the module uses only baseline APIs (`fetch`, `URLSearchParams`, `Intl`).
- Pico may be unreachable from the smoke run's Chrome (the run blocks it on purpose); the human check covers the styled
  result in a real browser.
