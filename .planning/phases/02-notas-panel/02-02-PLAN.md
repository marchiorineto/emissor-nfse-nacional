## Planning Decisions (Claude's discretion, recorded)

- **Cursor tiebreak (CONTEXT Claude's Discretion):** fixed in the repo with an optional `beforeId`; old callers that
  send only `before` keep today's meaning, so the `/v1` contract is unchanged. No migration: the `notas_created` index
  serves the first sort key and SQLite sorts only the ties (RESEARCH A5, accepted at this data size).
- **`limit` clamp (RESEARCH Pitfall 9, Open Question 1):** included because STATE.md lists it as a Phase 2 blocker.
  Invalid values fall back to the default 50 (as `limit=0` and non-numeric values already did) rather than to 1.
  It is isolated in Task 2 and in one helper, so the user can drop it without touching the rest. Rated `costly` below.
- **Download (D-18):** opt-in `?download=1` answering `attachment` with a number-based filename, recommended by
  RESEARCH over the `download` attribute alone (the server's `filename=` overrides the attribute). The default inline
  answer keeps its id-based filename byte for byte; its known failure for ids outside Latin-1 (RESEARCH Pitfall 7) is a
  pre-existing issue left out of scope and noted in a code comment and the SUMMARY.
