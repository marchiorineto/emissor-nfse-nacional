## Planning Decisions (Claude's discretion, recorded)

- **Link target (D-11):** the Número text is the link (the client name stays plain text).
- **Closing (D-13, D-14):** Fechar is a `<form method="dialog">` button (closes without JS); Esc is native; a click on
  the backdrop (event target is the dialog itself) closes too. The close handler clears the hash with `replaceState`.
  Accepted trade-off from RESEARCH Pattern 3: after closing with Fechar or Esc, one Back press lands on the same list
  URL without the dialog; `history.back()` on close is avoided because it would leave the site on a deep-link landing.
- **View-model (D-15, D-16, D-16a, D-20):** `format.js` returns plain data (`DetailSection[]`, `ErrorBox[]`, a notice
  string); `panel.js` only turns it into elements. Anchors come only from values `format.js` built: `#nota=` hashes, the
  relative PDF path and an `https://` lookup URL, and `panel.js` re-checks those three prefixes before creating an `<a>`.
- **Labels:** pt-BR row labels as listed in must_haves; export mode codes shown as 1 Transfronteiriço, 2 Consumo no
  Brasil, 3 Presença comercial no exterior, 4 Movimento temporário de pessoas; replacement reason shown as its code plus
  the free text; BACEN currency shown as its code (it is not an ISO code, RESEARCH).
