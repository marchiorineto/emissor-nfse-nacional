## Planning Decisions (Claude's discretion, recorded)

- **Filter control (Discretion):** a `<select>` (seven options fit, Pico styles it, one line of markup). Its labels are
  rendered by the server from `format.js`, which has no DOM access and so can be imported by `src/admin.ts`.
- **History (D-03):** `pushState` for filter changes, so Back restores the previous filter. `sync()` is idempotent and
  reads only the URL; plan 02-04 binds it to `hashchange` too.
- **Last page (D-02, D-04):** hide the button when a page has fewer than 20; with exactly 20 left, one extra click
  returns an empty page and hides it (RESEARCH Pitfall 10). No `limit=21` probe: D-04 fixes 20.
- **PDF link (D-18):** relative `/v1/notas/<encodeURIComponent(id)>/pdf?download=1` plus a `download` attribute; never
  the API's signed public link, which is built from PUBLIC_URL and may be cross-origin (the attribute is ignored there).
