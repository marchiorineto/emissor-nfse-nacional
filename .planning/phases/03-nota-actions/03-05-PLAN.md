## Planning Decisions (Claude's discretion, recorded)

- **Id before the GET (D-07, D-17):** the boot writes the new id into the URL before fetching the source, so a reload
  during the fetch also keeps it; the URL ends as `?de=<id>&id=painel-...`, the shape D-17 names.
- **Value prefill:** `formatBrlInput(cents)` writes '1.234,56' (no R$), which parseBrl reads back exactly.
- **Taker prefill:** the CPF/CNPJ goes in as stored digits (the field strips punctuation anyway).
- **Retry messages:** shown as a status line at the top of the dialog body after the re-render; failures that do not
  re-render (400, 403, network) use the same line.
- **Helpers in form.js:** duplicateHref, retryBody and canRetry sit with the other issue helpers, so the tests and
  declarations stay in one module.
- **Reversibility:** reversible (client-side helpers and links; no API change).

## Flagged Assumptions (not silently dropped)

- **EDGE ACT-03 and ACT-01/retry (edge probe: unclassified, unresolved):** the duplicate and retry edge truths (dropped
  abroad data, unknown source, reload keeps the id, hostile prefill, the replaces round trip) were written by hand from
  D-15 to D-17, D-10 and RESEARCH Pitfall 2; flagged for review, not probe-verified.
- **Retry on Sem resposta:** the server ignores the posted body for an unknown nota and resends its stored request
  (src/notas.ts); the panel sends the same stored request anyway, so the two never differ.
