## Planning Decisions (Claude's discretion, recorded)

- **Notice hand-off (D-09):** a hash flag, `#nota=<id>&ja-emitida`, in the same URL-as-truth style as `&cancelar`
  (D-11). It is text only; a crafted link can at most show a harmless notice.
- **Where hints show:** issueHints lines follow the error box, on the form and in the dialog (the box stays first, as
  Phase 2 D-16 put it).
- **Field errors:** a `small id="field-<key>-error"` right after the control (Pico paints it with the invalid control),
  referenced first in aria-describedby; cleared when that field changes and on every submit.
- **403:** the message plus a Recarregar button; reloading is safe because the id is in the URL.
- **Reversibility:** reversible throughout (client-side flag name, messages, CSS).
