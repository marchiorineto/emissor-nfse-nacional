## Planning Decisions (gap closure, recorded)

- **Classless build, not a container class** (UI-REVIEW top fix 1): keeps D-12's "classless or semantic" rule and plan
  01-02's no-class rule. Same version 2.1.1, same CDN path, so PAGE_CSP needs no change.
- **Logout button without a type attribute:** in a form a button submits by default; leaving the attribute off avoids
  Pico's full-width and bottom-margin rules for typed submit buttons, so "Sair" is a compact button vertically centered
  in the nav (checked in a headless Chrome render at planning time; with the attribute it sits taller and off-center).
- **Badges via Pico's `data-theme` attribute:** a data attribute, not a class, documented by Pico, readable without CSS.
  Homologação is forced to the light mark (beige, dark text) and produção to the dark mark (deep blue, white bold text),
  so they differ in both OS schemes; produção is also wrapped in `strong`. No CSP or stylesheet change is needed.
- **Copy alignment folded in** (UI-REVIEW Pillar 1 minors, same lines being rewritten): one product name on both pages
  ("Emissor de NFS-e"), the CNPJ labelled, an en dash as the title separator.
- **Not addressed, by design:** on wide screens the login field still spans the Pico container (up to 1200 px at a
  1280-1535 px viewport). Classless Pico has no narrower semantic wrapper; a class or custom CSS would break D-12 or the
  CSP. Re-test will show whether the user still minds it.
